# Toybox Trials — town concept pack v1

Four views of one original handcrafted tabletop town, generated with the built-in image tool.
For Claude Code: start with [HANDOFF.md](HANDOFF.md), then inspect the full-resolution images.

| Image | Use |
| --- | --- |
| [01 — Layout overview](01-layout-overview.png) | Landmark relationships and walking routes |
| [02 — South overview](02-south-overview.png) | Primary facades, construction materials and room scale |
| [03 — North reverse](03-north-reverse.png) | Rear panels, workshop hinges and scoreboard supports |
| [04 — Player approach](04-player-approach.png) | Plaza approach, atmosphere and illustrative character scale |

These are visual-development references, not game screenshots or calibrated blueprints.
Use the source coordinates and discrepancy notes in the handoff rather than tracing the art.
Extra cottages/decoration are proposals. No town geometry was implemented for this pack.

Generation provenance and exact prompts: [PROMPTS.md](PROMPTS.md). The first image was the
design reference for the other three; all outputs were visually inspected. Source assets are
recorded in `public/assets/asset-manifest.json` and stay outside the deployed game bundle.
