# Spellbox ability icon prompts

Generated for Toybox Trials on 19 November 2026 using the built-in `image_gen` tool, one call per icon. The Pop Rocket output was used only as the material/style reference for the other seven. All subjects are original project designs; no third-party reference artwork was supplied.

Final game assets: `public/assets/ui/spellbox/*.webp` (512×512, alpha preserved). Browser-native downsampling/WebP export is a production derivative; subjects were not retouched. UI names and cooldowns remain live text. Original full-resolution generation outputs remain in Codex's generated-image history and are not runtime dependencies.
