# public/assets/concepts

Art-direction reference images. **Never loaded by the game.** They are stripped from `dist/` by the
`toybox:strip-concept-art` plugin in `vite.config.ts`. Dimensions, sources, prompts and licensing are recorded in
`../asset-manifest.json`. Prompts for the images not yet generated are in `docs/04-concept-art-prompts.md`.
